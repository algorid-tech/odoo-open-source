📋 Overview

Madrashah Portal provides secure online access for parents and students to view academic information. Check attendance, fee status, exam results, and class timetables from anywhere, anytime.

📱 Mobile Responsive: Fully responsive design works seamlessly on smartphones, tablets, and desktop computers.

✨ Key Features

  • 👤 Student Profile

    View student profile, class information, and personal details.

  • 📅 Attendance History

    View attendance records with date-wise filtering and statistics.

  • 💰 Fee Status

    Check fee dues, payment history, and download receipts.

  • 🎓 Exam Results

    View exam results, marks, grades, and GPA with subject breakdown.

  • 🗓️ Class Timetable

    View weekly class schedule with subjects and teachers.

  • 👨‍👩‍👧 Multi-Student (Guardian)

    Guardians can view information for all their children from single login.

  • 🔐 Secure Access

    Secure login with email verification and password reset.

  • 📱 Mobile Friendly

    Responsive design for optimal viewing on all devices.
