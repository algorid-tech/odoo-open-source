📋 Overview

Madrashah Fees Management provides comprehensive fee collection and payment tracking for educational institutions. Define fee structures, generate invoices, track payments, and manage discounts with full integration to Odoo Accounting.

🔗 Odoo Accounting Integration: Seamlessly integrates with Odoo's accounting module for proper journal entries, invoicing, and financial reporting.

✨ Key Features

  • 📊 Fee Structures

    Define class-wise fee structures with multiple fee types and amounts.

  • 🏷️ Fee Types

    Create various fee types: Tuition, Admission, Exam, Transport, Library, etc.

  • 📄 Bulk Invoice Generation

    Generate fees for entire class/section at once for a specific period.

  • 💳 Payment Tracking

    Track partial and full payments with multiple payment methods.

  • ⏰ Late Fee Calculation

    Automatic late fee calculation based on due date and grace period.

  • 🎁 Discounts

    Apply discounts: sibling, scholarship, staff children, merit-based.

  • 📧 Payment Reminders

    Send payment reminders to parents for overdue fees.

  • 🌐 Portal Access

    Parents can view fee status and payment history via portal.
