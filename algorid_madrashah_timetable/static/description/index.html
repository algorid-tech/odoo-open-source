📋 Overview

Madrashah Timetable Management provides an intuitive weekly timetable builder for classes. Create and manage class schedules with automatic conflict detection to prevent double-booking of teachers and rooms.

⚠️ Smart Conflict Detection: Automatically detects and alerts when a teacher is assigned to multiple classes at the same time, or when a room is double-booked.

✨ Key Features

  • 📅 Weekly Timetable Builder

    Create weekly schedules for each class/section with drag-and-drop ease.

  • ⏰ Period Management

    Define periods with start/end times, including breaks and lunch.

  • ⚠️ Conflict Detection

    Automatic detection of teacher and room conflicts across timetables.

  • 👨‍🏫 Teacher Assignment

    Assign teachers to specific periods with subject mapping.

  • 🏠 Room Assignment

    Assign rooms/labs to specific periods for practical classes.

  • 📤 Export & Print

    Export timetables to PDF for printing and distribution.

  • 📋 Copy Timetable

    Copy existing timetable to new academic year with modifications.

  • 🌐 Portal Access

    Students and parents can view class timetable through portal.
