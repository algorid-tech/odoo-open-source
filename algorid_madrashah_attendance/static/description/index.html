📅 Attendance Management

Madrashah Management System - Daily Attendance Tracking

Odoo 19 Community Student Attendance Teacher Attendance Reports & Analytics

📋 Overview

Madrashah Attendance Management provides comprehensive daily attendance tracking for both students and teachers. Quick attendance marking, attendance sheets, and detailed reports with export capabilities.

⚡ Quick Attendance: Mark attendance for entire class at once using attendance sheets. Bulk operations for efficiency.

📊 Attendance Status Types

✓ Present ✗ Absent ⏰ Late 📋 On Leave

✨ Key Features

  • 👨‍🎓 Student Attendance

    Daily attendance for students by class and section with multiple status options.

  • 👨‍🏫 Teacher Attendance

    Track teacher attendance with check-in/check-out times and leave management.

  • 📝 Attendance Sheets

    Bulk attendance marking using attendance sheets for entire class at once.

  • 📊 Reports & Dashboard

    Comprehensive attendance reports by student, class, date range with statistics.

  • 📤 CSV Export

    Export attendance data to CSV for external reporting and analysis.

  • 🌐 Portal Access

    Parents and students can view attendance history through the portal.

📈 Available Reports

Report Description
Daily Attendance Class-wise attendance for a specific date
Monthly Report Student-wise attendance summary for a month
Absentee Report List of absent students for follow-up
Attendance Percentage Attendance percentage by student/class
