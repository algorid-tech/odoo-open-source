Product Packaging Import from Excel

Import packaging data efficiently from Excel files

Features

Excel Import

Upload .xls or .xlsx files with packaging data. Support for both old and new Excel formats.

Template Download

Generate pre-formatted Excel templates with instructions and example data.

Product Filtering

Import packaging for specific products or entire product templates.

Smart Validation

Detailed error reporting with row numbers and helpful error messages.

How It Works

Method 1: From Configuration Menu

  1. Navigate to Inventory → Configuration → Import Packaging
  2. Download the Excel template
  3. Fill in your packaging data
  4. Upload and import

Method 2: From Product Form

  1. Open any product template or variant
  2. Click the "Import Packaging" smart button
  3. Download template (pre-filled with product info)
  4. Fill in packaging data
  5. Upload and import (automatically filtered)

Supported Fields

Field Required Description
Product Code/ID Required Product default code or database ID in brackets [123]
Packaging Name Required Name for the packaging
Contained Quantity Required Number of products in this packaging
Sequence Optional Order number (lower = default)
Barcode Optional Barcode for scanning
Package Type Optional Package type name (must exist)
Sales Optional Available for sales (TRUE/FALSE)
Purchase Optional Available for purchase (TRUE/FALSE)
Routes Optional Comma-separated route names

Installation

Install the required Python dependencies:

pip install openpyxl xlrd

Then install the module from Odoo Apps menu.
