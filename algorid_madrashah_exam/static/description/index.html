🎓 Exams & Results Management

Madrashah Management System - Complete Examination System

Odoo 19 Community Exam Scheduling Auto Grading Report Cards

📋 Overview

Madrashah Exams & Results provides a complete examination management system from scheduling exams to generating report cards. Automated grade calculation, GPA computation, and professional report card generation.

🤖 Automatic Calculations: Grades, GPA, percentages, and pass/fail status are automatically calculated based on configurable grading rules.

📊 Grading System

A+ (80-100) A (70-79) A- (60-69) B (50-59) C (40-49) D (33-39) F (<33)

Fully configurable grade boundaries and grade points

✨ Key Features

  • 📅 Exam Calendar

    Create exam calendars with dates, times, and room assignments for each subject.

  • 📝 Marks Entry

    Easy marks entry wizard for teachers to enter marks subject-wise.

  • 🔢 Auto Grade Calculation

    Automatic calculation of grades based on configurable grading rules.

  • 📊 GPA Calculation

    Automatic GPA calculation based on grade points and credit hours.

  • 📄 Report Cards

    Professional report card generation with school logo and signatures.

  • 📈 Result Analysis

    Class-wise and subject-wise result analysis and statistics.

  • 🔄 Result Workflow

    Draft → Confirmed → Published workflow for result management.

  • 🌐 Portal Access

    Students and parents can view results through the online portal.

📚 Supported Exam Types

Exam Type Description

Final Exam Annual/Final examinations
