Complete Islamic Educational Institution Management Solution

Odoo 19 Community Bilingual: English & বাংলা Open Source

📋 Overview

Madrashah Management System - Base Module is the core foundation for managing Islamic educational institutions (Madrasah/Madrashah). This module provides essential configurations including academic years, classes, sections, and subjects management.

🌐 Bilingual Support: Full support for both English and Bangla (বাংলা) languages, making it perfect for institutions in Bangladesh and Bengali-speaking regions worldwide.

✨ Key Features

  • 📅 Academic Year Management

    Define academic years with start/end dates. Set current academic year for the institution.

  • 🏫 Class Management

    Create and manage classes with capacity limits, assigned teachers, and linked subjects.

  • 📚 Section Management

    Organize classes into sections (A, B, C) with individual capacity and room assignments.

  • 📖 Subject Management

    Define subjects with codes, credit hours, and subject types (compulsory/optional).

  • 🔐 Security Groups

    Pre-configured security roles: Admin, Teacher, Accountant, Parent, Student.

  • ⚙️ System Configuration

    Centralized settings for institution name, fee policies, and academic preferences.
