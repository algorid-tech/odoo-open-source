👨‍🎓 Student Management

Madrashah Management System - Complete Student Information System

Odoo 19 Community Student Profiles Guardian Management

📋 Overview

Madrashah Student Management provides comprehensive student information system for Islamic educational institutions. Manage student profiles, guardian information, documents, and track student lifecycle from admission to graduation.

🎓 Complete Student Lifecycle: From admission (draft) → active student → graduation or leaving, track every stage of the student journey.

✨ Key Features

  • 📝 Student Profiles

    Complete student profiles with personal info, photos, contact details, and academic information.

  • 👨‍👩‍👧 Guardian Management

    Link multiple guardians (father, mother, others) to students with emergency contact flags.

  • 📄 Document Management

    Store and manage student documents: birth certificates, photos, previous certificates.

  • 🏷️ Student Tagging

    Tag students for special categories: scholarship, special needs, transport, hostel.

  • 🔄 Status Workflow

    Track student status: Draft → Active → Graduated/Left/Suspended with full history.

  • 🌐 Portal Access

    Create portal users for students and guardians to access their information online.

  • 🎴 ID Card Generation

    Generate and print student ID cards with photos and barcodes.

  • 📊 Auto Roll Numbers

    Automatic roll number generation based on class and section.

📑 Student Information Captured

Category Fields
Personal Name (English & Bangla), Date of Birth, Gender, Blood Group, Religion, Nationality
Academic Student ID, Roll No, Class, Section, Academic Year, Admission Date
Family Father's Name, Mother's Name, Guardian Details, Emergency Contacts
Contact Address, Mobile, Email, Present & Permanent Address
Medical Blood Group, Medical Conditions, Allergies
