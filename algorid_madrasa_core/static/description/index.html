Key Features of Merge Sale Order Line

  • This module allows users to merge duplicate lines in a sale order.
  • Duplicate lines can be merged both automatically or manually during order creation or editing.
  • Support both community and enterprise edition.

Merge Duplicate Sale Order Line Manually

  • Users can merge duplicate lines by clicking the "Merge Duplicate Lines" button.


Merge Duplicate Sale Order Line Automatically

  • Duplicate sale order lines can also be merged automatically during order creation or editing, if enabled from the settings.
